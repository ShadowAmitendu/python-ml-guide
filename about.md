## About This Blog

**Python ML Guide** is a free, open-source, step-by-step blog that teaches Machine Learning using Python — from absolute zero.

### Who Is This For?

- 🎓 **Students** starting out with ML
- 💻 **Developers** who want to add ML to their skillset
- 🔍 **Curious minds** who want to understand how ML works

### What Makes This Different?

- **No jargon walls** — every concept is explained in plain English first
- **Hands-on code** — every post includes runnable code you can try immediately
- **Multiple setup options** — whether you use Colab, Jupyter, VS Code, or PyCharm
- **Step-by-step progression** — each post builds on the previous one

### Tech Stack

All code in this blog uses:

- **Python 3.10+**
- **NumPy**, **Pandas** — data handling
- **Matplotlib**, **Seaborn** — visualization
- **Scikit-Learn** — classical ML
- **TensorFlow / PyTorch** — deep learning (later posts)
